## How to use

1. Pick a tool
2. Click **Deploy with Vercel**
3. Add your `ANTHROPIC_API_KEY` when prompted
4. Your instance is live

Or fork the repo and customise -- every configurable tool uses `config.js` for branding, data sources, and AI prompts.

## Stack

Every tool: vanilla HTML/CSS/JS + Vercel serverless + Claude API. Zero dependencies. Fork → configure → deploy.
